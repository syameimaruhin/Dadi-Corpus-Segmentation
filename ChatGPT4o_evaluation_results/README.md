# About Evaluation Results

This directory contains the raw segmentation outputs generated by **ChatGPT-4o**.

## Why only ChatGPT-4o?
Unlike traditional segmentation tools, Large Language Models (LLMs) operate via cloud APIs and their outputs are **non-deterministic**. Factors such as temperature settings, unannounced model updates, and internal randomness can cause outputs to vary even with identical prompts. 

For the other baseline tools mentioned in the paper (e.g., Jieba, HanLP) and our proposed **BMM method**, the results are **fully deterministic**. Researchers can perfectly reproduce those segmentation results locally by utilizing the raw text, the provided "Dadi Corpus Word Segmentation User Dictionary" (ver 1.0 & 2.0), and the Python scripts available in the main repository. Providing raw results for ChatGPT-4o is therefore essential for ensuring the transparency and reproducibility of our evaluation metrics.

## Directory Structure

- `Randomly Sampled Chinese Texts/`: Raw outputs for Chinese sample sets.
- `Randomly Sampled Japanese Texts/`: Raw outputs for Japanese sample sets.
- `Zuo Zhuan/`: Raw outputs for _Zuo Zhuan_.
- `Stability_Testing_Zuo_Zhuan/`: Contains 5 repetitive trials to evaluate system stability. To facilitate immediate verification, we have also included **`gold_standard_Stability_Testing.txt`** in this folder, which is the specific subset of the Zuo Zhuan gold standard used for this 1,210-character test.

## Special Note on System Determinism
As discussed in **Section 4.6** of the paper, LLMs exhibit significant volatility when processing ancient texts. The 5 trials in the `Stability_Testing_Zuo_Zhuan/` folder resulted in the following F1-scores:
- **Trial 1:** 0.7660
- **Trial 2:** 0.8005
- **Trial 3:** 0.1739
- **Trial 4:** 0.3850
- **Trial 5:** 0.6783

This high variance illustrates why LLMs can be unreliable for large-scale, high-precision corpus construction where "textual faithfulness" and "predictability" are primary requirements.
