### About Evaluation Results

This directory contains the raw segmentation outputs generated by **ChatGPT-4o**. 

**Why only ChatGPT-4o?**

Because Large Language Models (LLMs) operate via cloud APIs and their outputs can be non-deterministic or subject to unannounced model updates, providing these raw results is essential for ensuring the reproducibility of the evaluation metrics reported in our paper. 

For the other baseline tools mentioned in the paper (e.g., Jieba, HanLP) and our proposed BMM method, the results are fully deterministic. Researchers can perfectly reproduce those segmentation results locally by utilizing the raw text, the provided **"Dadi Corpus Word Segmentation User Dictionary" (both ver 1.0 and ver 2.0)**, and the Python scripts available in the main repository.
