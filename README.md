# Dadi-Corpus-Segmentation

This repository contains the official data, materials, and source code for the paper: **Research on the Development and Optimization of Word Segmentation Function for the "Dadi Corpus"
——A Method Based on Mutual Information and Multi-character Mutual Information**.

This project aims to provide a highly stable, deterministic, and textually faithful word segmentation framework optimized for ancient Chinese and Sino-Japanese (*Kanbun*) texts, utilizing Mutual Information (MI) and Multi-character Mutual Information (MMI).

## 📁 Repository Structure

### 1. Core Algorithms & Scripts
- `01_FMM_segmentation.py`: Forward Maximum Matching (FMM) segmentation script.
- `02_RMM_segmentation.py`: Reverse Maximum Matching (RMM) segmentation script.
- `03_BMM_tie_break.py`: Bi-directional Maximum Matching (BMM) script with tie-breaking rules.
- `04_Ngram_MI_calculator.py` & `05_Ngram_MMI_calculator.py`: Calculators for Mutual Information (MI) and Multi-character MI (MMI) used in Out-of-Vocabulary (OOV) word extraction.
- `06_Corpus_Random_Sampling.py`: Script for random sampling from the corpus.
- `07_MI_Threshold_Selection.py` & `08_MMI_Threshold_Selection.py`: Scripts to determine optimal thresholds for new word discovery.
- `09_Fleiss_Kappa_Adjudication.py`: Script for calculating inter-annotator agreement (Fleiss' Kappa).

### 2. Dictionaries & Data (Open Data)
- `Dadi Corpus Word Segmentation User Dictionary (ver 1.0).txt`: The baseline "Dadi Corpus Word Segmentation User Dictionary (ver 1.0)".
- `Dadi Corpus Word Segmentation User Dictionary (ver 2.0).txt`: The optimized "Dadi Corpus Word Segmentation User Dictionary (ver 2.0)".
- `gold_standard for Randomly Sampled Chinese Texts.txt`: Ground truth data for Chinese text evaluation.
- `gold_standard for Randomly Sampled Japanese Texts.txt`: Ground truth data for Japanese text evaluation.

### 3. Guidelines & Evaluation Results
- `Annotation_Guidelines.md`: The detailed manual annotation rules used for creating the gold standard.
- `evaluation_results/`: A directory containing the raw segmentation outputs generated by **ChatGPT-4o** for reproducibility and comparison. (Please refer to the README inside this folder for details).

## 🚀 How to Reproduce

To reproduce the optimal segmentation results reported in our paper:

1. Ensure you have Python 3.x installed.
2. Place the raw ancient texts you wish to segment in the same directory.
3. Run the BMM script (`03_BMM_tie_break.py`) and load the optimized user dictionary (`Dadi Corpus Word Segmentation User Dictionary (ver 2.0).txt`).
4. The script will output the segmented text.
